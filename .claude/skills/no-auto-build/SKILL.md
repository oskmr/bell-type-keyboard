# ビルド自動実行の禁止

## 重要な原則

**ビルド操作は、ユーザーが明示的に指示した時のみ実行すること。**

コードを修正したり、新機能を追加した後も、自動的にビルドやデプロイを行わないこと。

## 明示的な指示の例

以下のような明示的な指示があった場合**のみ**ビルドする：

- 「ビルドして」
- 「実機にビルドして」
- 「デプロイして」
- 「iPhoneで動かして」
- 「シミュレータで確認して」
- 「アーカイブして」
- 「実機で確認して」

## 自動ビルドしない例

以下のような場合は**ビルドしない**：

- コードを修正した後
- 新しい機能を追加した後
- バグを修正した後
- ファイルを変更した後
- ユーザーが「変更を確認して」と言った時
- ユーザーが「次は？」と尋ねた時
- ユーザーが「どうなった？」と尋ねた時

## 適切な対応

ビルドの明示的な指示がない場合は：

1. コード変更を完了する
2. 変更内容を説明する
3. **ビルドせずに終了する**
4. 必要であれば「実機で確認する場合は『ビルドして』と指示してください」と案内する

## ビルドが必要か判断に迷う場合

**迷ったらビルドしない。** ユーザーが必要と判断すれば指示してくる。

## 対象となるビルド操作

- `xcodebuild` コマンド
- `ios-device-build` スキル
- シミュレータビルド
- 実機ビルド・デプロイ
- アーカイブ・リリースビルド
- その他すべてのビルド関連操作
