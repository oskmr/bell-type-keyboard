# リモート最新の取得

## トリガー

以下のような発言があった場合に適用する：

- 「最新にして」
- 「最新にしてほしい」
- 「最新を取得して」
- 「リモートの最新を取って」
- 「最新のファイルを取得して」

## 実行内容

1. ワークスペースのルートで `git pull` を実行する
2. `network` と `git_write` 権限をリクエストする
3. 実行結果（更新されたファイル一覧など）をユーザーに報告する

## 注意

- パッケージのバージョン更新（例：RevenueCat の最新化）ではない
- リモートリポジトリから最新のコミットを取得する操作である
